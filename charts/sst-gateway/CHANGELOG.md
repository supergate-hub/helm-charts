# Changelog

## 1.0.0 (2026-09-15)

### Features

* initial release: Traefik 41.5.0 wrapped with the isolated namespace, Gateway API v1.6.1 CRDs and admission policy, GatewayClass and Gateway, scoped RBAC, cert-manager certificate mirroring, canary backend, Kubernetes and Cilium network policies and a PrometheusRule. Renders identically to the manifests previously generated by infra-ops `render_gateway.py` with the same values, except that the Traefik pod keeps the default `enableServiceLinks`.
